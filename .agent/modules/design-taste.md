- Do **not** use glossy glassmorphism (heavy shadows, reflections, bevels, mirror glass).
- Do **not** treat pale circle-overlap bokeh as a substitute for frosted UI overlays.

# amigo-habeas-frosted

## Use this skill when

Use this skill when the output should read as a restrained editorial/modular visual system built from:

- Large serif display typography.
- Small sans-serif support text.
- Generous whitespace.
- Strict alignment rails.
- Low-contrast hairline rules.
- Narrow matte palettes.
- Contained photography or atmospheric panels.
- Moderate rounded rectangles.
- Pale frosted translucency, warm muted slabs, dark atmospheric panels, or precise card/grid systems.

Use it for posters, covers, editorial pages, documents, landing pages, product pages, interfaces, dashboards, card grids, comparison tables, galleries, abstract assets, palette sheets, and sparse footer/base-band systems only when the requested medium supports those structures.

Do not use this skill to create generic startup UI, luxury branding, dense SaaS dashboards, glossy glass interfaces, decorative illustration systems, or content-heavy marketing templates.

## Core directive

Build the composition from visible constraints: scale contrast, serif-led hierarchy, strict rails, generous margins, staged density, narrow color roles, matte surfaces, contained atmospheric imagery, moderate rounded modules, faint rules, and sparse microtypography.

Choose one primary focal system only:

- One large serif headline.
- One large contained image or atmospheric panel.
- One large warm or dark color mass.
- One precise structured grid.

Do not create multiple competing focal systems. Do not fill open space with decoration. Do not use vague luxury, startup, or tech clichés as substitutes for the actual visual grammar.

## Visual grammar

Use this grammar as the default:

1. Start with a restrained editorial structure.
2. Make the primary element visibly dominant through scale, mass, placement, value, and whitespace.
3. Make secondary copy, labels, metadata, navigation, captions, and controls dramatically smaller than the primary element.
4. Use a narrow palette with 3–5 functional roles:
   - Warm off-white, ivory, cream, pale gray, or pale blue-gray ground.
   - Dark primary text.
   - Muted secondary text and rules.
   - One accent hue family.
   - Optional dark base or dark panel.
5. Concentrate accent color into one or two large block-level surfaces.
6. Use alignment, spacing, scale, value, opacity, and mass before color, weight, shadow, or decoration.
7. Keep surfaces matte and flat.
8. Create depth with overlap, low-opacity fills, value shifts, contained blur, atmospheric imagery, and translucent intersections.
9. Do not use heavy shadows, gloss, bevels, chrome, metallic effects, or reflective glass.
10. Keep abstract complexity bounded inside panels, slabs, tiles, cards, or controlled fields.
11. Treat microtypography as precise visual texture.
12. Use rounded rectangles for panels, cards, image containers, slabs, and media modules.
13. Keep radii moderate: softened corners, not bubbles.
14. Balance rounded modules with straight rules, strict rails, equal gutters, and rectilinear grid logic.
15. Maintain low-to-moderate density overall.
16. Restrict high density to bounded grids, tabular rows, metadata strips, or card sections.
17. Preserve compatible modes:
   - Serif editorial layouts.
   - Pale translucent grid systems.
   - Warm block-accent compositions.
   - Dark atmospheric panels.
   - Contained image/card systems.

## Composition and layout

Start every layout with a clear hierarchy:

1. Primary display type or primary visual mass.
2. Secondary copy or modules.
3. Micro labels, details, rows, annotations, or controls.

Use broad outer margins. Inset all text, controls, cards, and structured content from canvas edges. Allow intentional edge cropping only for images, atmospheric circles, blurred forms, abstract panels, or color fields.

Use large negative space as an active visual element. Place it above dense modules, beside large headlines, opposite image anchors, or around centered title structures.

Prefer left-aligned editorial split layouts for text-led compositions. Use strict vertical rails for:

- Headline edges.
- Copy blocks.
- Labels.
- Image edges.
- Grid columns.
- Card boundaries.
- Rule positions.

Use centered compositions only when the structure is clearly:

- Title-led.
- Comparison-led.
- Calm and ceremonial.
- A centered title block above cards, rows, or a grid.

Stage density from open to dense:

- Use an airy headline area above compact lower rows.
- Use spacious left text beside denser right image modules.
- Use an open top title above a card grid.
- Use one dense zone beside one quiet field.
- Use one large image tile against multiple smaller tiles.
- Use one large color slab or dark base band to balance typographic openness.

Do not make all regions equally detailed. Confine detail to one or two zones.

For grids and cards:

- Use equal column widths.
- Use consistent gutters.
- Use repeated padding.
- Use repeated moderate radius.
- Use consistent label placement.
- Use consistent divider style.
- Define separation through whitespace, faint rules, thin borders, or tonal shifts.
- Avoid heavy boxes and dashboard chrome.

For rows, tables, and lists:

- Use hairline horizontal rules.
- Keep dividers low-contrast.
- Use small centered marks only when needed.
- Use muted micro labels and annotations.
- Use thin vertical rules only as quiet alignment markers.
- If a focal comparison column is needed, use one continuous rounded accent slab spanning multiple rows.

For containment:

- Use inset rectangular borders or internal frames when sparse compositions need structure.
- Keep frames thin, low-contrast, and visibly inset.
- Use dark footer/base bands only to ground an airy, pale, or atmospheric composition.
- Keep dark base bands shallow, sparse, and uncluttered.
- Place small marks near left and right edges with a largely empty center when using base bands.

## Typography and lettering

When a headline or primary statement exists, set it in a large serif display face. Make it the dominant visual object.

Break serif headlines deliberately across multiple lines. Shape the text block into a clear rectangular, stacked, or sculptural silhouette.

Use restrained type weights. Do not rely on bold weight as the main hierarchy device.

Pair display serif type with small sans-serif type for:

- Supporting copy.
- Labels.
- Captions.
- Metadata.
- Navigation.
- Buttons.
- Pills.
- Tabs.
- Annotations.
- Row labels.
- Interface controls.

Make supporting text dramatically smaller than the headline. The scale jump must be obvious immediately.

Keep supporting paragraphs:

- Narrow.
- Compact.
- Muted.
- Short in line length.
- Subordinate to the headline or visual mass.

Use tiny uppercase, tracked, or annotation-like labels as a tertiary layer.

Treat dense microtype, captions, navigation, row labels, and metadata as precise texture. Align it to rails, rules, panel edges, grid columns, or module centers.

Use left alignment for:

- Editorial split layouts.
- Lists.
- Rows.
- Image captions.
- Structured modules.
- Supporting text blocks.

Use centered text only in:

- Centered title stacks.
- Calm comparison structures.
- Symmetrical cover/poster-like title arrangements.

Keep navigation small, quiet, and secondary. Do not make it large, bold, colorful, or dominant.

Keep buttons, pills, tabs, filters, and controls small and subordinate. If a warm filled button is required, use only one high-emphasis accent button.

Use thin outlined pills or small filled pills as delicate marks. Do not use oversized promotional CTA buttons.

On image tiles or catalog-like modules, place embedded micro-labels consistently inside the image container.

Keep symbolic marks:

- Small.
- Flat.
- Repetitive.
- Centered.
- Aligned to a clear axis.

Do not enlarge checkmarks, x-marks, arrows, icons, or status symbols into decorative hero graphics.

Do not distort, warp, bevel, extrude, gloss, or apply 3D effects to type.

On dark fields, set primary type in soft ivory or off-white. Set secondary text in muted low-opacity gray, gray-blue, or pale gray.

On warm terracotta, rust, brick, burnt coral, red-brown, or burnt sienna fields, use sparse white or off-white typography with strict spacing discipline.

Microtext may function as visual texture when exact legibility is not central. Do not invent dense functional content just to fill space.

## Color and value

Use a narrow palette. Limit each composition to 3–5 functional color roles.

Default roles:

- Ground: warm off-white, ivory, cream, near-white, pale gray, or pale cool blue-gray.
- Primary text: deep teal-black, navy, charcoal, dark brown-black, or dark chromatic neutral.
- Secondary text/rules: muted gray, gray-blue, pale gray, or low-opacity neutral.
- Accent: one hue family only.
- Optional base/panel: deep teal-black, navy, charcoal, or dark chromatic field.

Use warm off-white, ivory, cream, or near-white instead of stark white when the composition needs soft editorial restraint.

Use deep teal-black, navy, charcoal, or dark chromatic fields instead of pure black for dark atmospheric layouts.

Use soft ivory or off-white type on dark grounds to reduce glare.

Use one accent hue family per composition. Do not introduce multiple unrelated saturated accents.

When warmth is required, default to muted earth accents:

- Terracotta.
- Rust.
- Brick red.
- Burnt coral.
- Dusty red-brown.
- Burnt sienna.

Concentrate warm accent color in large surfaces:

- Cards.
- Slabs.
- Panels.
- Fields.
- One major block.
- One continuous comparison column.

Do not scatter accent color across icons, bullets, links, buttons, highlights, tabs, and decorative flecks.

Compatible palette modes:

- Neutral off-white, blackened chromatic text, muted gray, and one warm earth accent.
- Deep teal, navy, or charcoal with ivory and muted gray.
- Monochromatic muted red or terracotta fields with sparse light type.
- Pale cool blue-gray systems with translucent overlapping forms.
- Pale editorial grounds with one dark image panel or shallow dark base band.

Keep saturation controlled. Avoid bright, neon, rainbow, iridescent, jewel-tone, or highly saturated gradient palettes.

Use value contrast for hierarchy. Let dark panels or dark text carry stronger value density than pale grounds. Keep secondary elements recessed.

Keep dividers and borders low-contrast. They must be visible but never more dominant than type, image, or accent mass.

Separate panels with slight value, temperature, opacity, border, or layering shifts. Do not use heavy shadows.

Use a dark footer/base band as the strongest value break only when it compositionally grounds an airy upper field.

Do not use black-and-gold, metallic gold, marble white, jewel-tone luxury palettes, or semantic rainbow status colors unless explicitly required by the prompt. If status states are required, keep them muted, small, and subordinate.

## Imagery, shape, texture, and material

Use photography as contained atmosphere, not as full-page decoration.

Crop photography inside:

- Rounded rectangles.
- Uniform cards.
- Square tiles.
- Consistent image containers.
- Large contained panels.

Use image panels as large visual anchors inside otherwise minimal layouts.

Unify varied imagery with identical or clearly related:

- Panel geometry.
- Corner radius.
- Caption position.
- Inset padding.
- Alignment.
- Crop logic.

Favor photography that is:

- Warm.
- Shadowed.
- Cinematic only in a restrained atmospheric sense.
- Documentary.
- Low-light.
- Naturalistic.
- Low-detail.
- Contained inside bounded modules.

Do not interpret cinematic imagery as lens flares, spectacle, aggressive contrast, oversaturated grading, or movie-poster drama.

Use dark square or near-square tiles as repeated anchors when image-led rhythm is needed. Inside dark tiles, use soft blurred bands, haze, vertical tonal marks, low-detail textures, or subdued atmospheric forms. Keep all such complexity inside the tile.

Use abstract atmospheric panels as bounded surfaces:

- Blurred blocks.
- Translucent rectangles.
- Luminous muted gradients.
- Oversized circles.
- Halftone texture.
- Low-detail tonal fields.
- Soft internal fades.

When frosted overlays sit over photography or rich atmospheric panels, require matte frosted overlays as a depth system:

- Soft blur band over the substrate (backdrop-style diffusion ~20–40px, not specular shine).
- Warm or cool translucent fill at low-to-mid opacity (~0.2–0.3).
- Quiet gray or hairline border; keep edges crisp on the chip/panel.
- Matte finish only — no reflections, chrome, or heavy drop shadows on the overlay.

Pale translucent circles inside a photo are atmospheric bokeh, not a substitute for frosted UI overlays. Ban glossy reflective glassmorphism; do not collapse matte frosted overlays into a blanket “remove glass effects” rule when overlay-over-imagery frost is evidenced.

Use hard-edged translucent rectangles with soft internal fades for warm atmospheric fields.

Keep crisp edges on cards, rules, type, frames, and geometric modules even when internal imagery or atmosphere is soft.

Use stacked rounded modules of equal sizing and consistent gutters for precise technical structures.

Pair compact modules with small annotation labels aligned to a second vertical axis.

Use hairline borders and thin outlines for:

- Modules.
- Panels.
- Swatches.
- Frames.
- Structured zones.
- Cards.

Keep all surfaces matte and flat.

Avoid:

- Heavy shadows.
- Glossy highlights.
- Reflective glassmorphism.
- Bevels.
- 3D extrusion.
- Chrome UI surfaces.
- Metallic finishes.
- Plastic shine.

Use texture at low to moderate intensity. Texture must not obscure grid structure, type hierarchy, or alignment.

Do not spread blur, haze, halftone, or photographic complexity across the full canvas when the system calls for bounded panels.

Do not use literal explanatory illustrations as a default substitute for atmosphere, contained photography, abstract blur, or color fields.

## Content and subject treatment

Make the aesthetic come from structure, not subject matter.

Use typography, spacing, grids, color mass, linework, contained images, rounded modules, and atmospheric surfaces as the style engine.

Do not depend on domain-specific content to create the look.

Discard exact names, brands, logos, proprietary marks, organization names, and wordmarks unless the user explicitly supplies them as required content.

Discard exact source wording, quotes, testimonials, metadata, labels, navigation text, button labels, table row names, and category terms unless the user supplies final copy.

If placeholder text is needed:

- Keep it short.
- Keep it quiet.
- Keep it subordinate.
- Use it only to preserve typographic hierarchy.
- Do not add narrative clutter.

Do not infer healthcare, medical, AI, SaaS, recruitment, corporate, workflow, institutional, or platform content unless the user asks for that domain.

Do not add:

- Credibility badges.
- Credentials.
- Customer proof.
- Metrics.
- Percentages.
- Institutional signals.
- Testimonials.
- Claims.

If a layout resembles a comparison table, testimonial, dashboard, palette sheet, case study, product page, or article index, retain only the visible layout behavior:

- Rows.
- Cards.
- Labels.
- Columns.
- Dividers.
- Slabs.
- Hierarchy.
- Contained modules.

Treat checkmarks, x-marks, active indicators, and status marks as small centered repetitive visual marks unless the prompt requires semantic meaning.

Keep photography subjects incidental. Preserve cropping, color, shadow, containment, and module geometry rather than literal people, places, objects, activities, or events.

Do not add stock corporate scenes, medical motifs, AI brain/network graphics, workflow diagrams, team portraits, generic business imagery, or institutional badges as style shortcuts.

Do not overpopulate footers, base bands, navigation bars, metadata zones, or card grids with invented content.

Make labels and annotations visually precise and sparse. Use uppercase, tracking, muted color, and micro-scale when appropriate.

Keep copy blocks short and narrow unless the requested deliverable is explicitly long-form.

The final design must read as an editorial/modular visual system, not as a content-heavy marketing template.

## Medium-specific rules

### Posters and covers

- Use a large serif title as the main object.
- Break the title across multiple lines with a strong block silhouette.
- Use small sans-serif metadata as quiet texture.
- Leave large open fields around the title.
- Add one contained atmospheric panel, one warm slab, or one dark base band only if needed for balance.
- Do not add extra icons, badge clusters, or decorative filler.

### Editorial pages and documents

- Use strict margins.
- Use left alignment.
- Use narrow support text.
- Use faint section rules.
- Let serif headlines dominate.
- Keep body copy compact and muted.
- Use image panels as contained anchors rather than full-bleed spreads.
- Use lower rows, captions, or metadata bands for controlled density.

### Landing pages and product pages

- Do not default to generic startup hero styling.
- Use serif hero typography.
- Use small quiet navigation.
- Use generous whitespace.
- Keep calls to action small.
- Use only one accent button if a button is required.
- Place product, image, or atmospheric modules in rounded containers with consistent geometry.
- Use split layouts or centered title-over-card structures.
- Do not build dense component libraries.

### Interfaces and dashboards

- Treat technical detail as precise alignment, thin rules, small annotations, muted labels, and structured rows.
- Do not treat technical detail as dense analytics chrome.
- Use hairline dividers.
- Use low-contrast panels.
- Use small controls.
- Avoid heavy card shadows.
- Avoid equal-weight dashboard tiles.
- Repeat card structure, radius, padding, and divider logic.
- Keep active states subtle: one muted fill, one thin outline, or one small accent mark.
- Do not use many bright status colors.
- Keep buttons, tabs, pills, filters, and navigation secondary.

### Multi-card grids and indexes

- Use equal-width columns.
- Use consistent gutters.
- Place a centered or left-aligned title block above the grid.
- Separate cards with whitespace, faint dividers, thin borders, or tonal shifts.
- Vary internal content only through headline length, image crop, texture, or small mark placement.
- Keep geometry consistent.

### Comparison tables and structured rows

- Use faint horizontal rules.
- Use small centered marks.
- Use one continuous rounded accent slab if a focal column is needed.
- Keep row labels and annotations micro-scale and muted.
- Do not turn the table into a colorful status dashboard.

### Image collages and galleries

- Use rounded image containers with consistent radii.
- Balance one large image against smaller tiles when using asymmetry.
- Use embedded micro-labels only when they support archival or catalog structure.
- Keep photos naturalistic, warm, shadowed, or atmospheric.
- Avoid spectacle, full-canvas collage chaos, inconsistent radii, and inconsistent caption placement.

### Abstract or atmospheric assets

- Use bounded translucent rectangles, oversized pale circles, blurred bands, halftone texture, or muted gradients.
- Keep atmospheric surfaces matte and low-saturation.
- Pair soft internal atmosphere with crisp external grids, borders, and typography.
- Do not let abstract texture overwhelm the composition.
- Do not interpret frosted as glossy glassmorphism.

### Palette sheets, swatches, and visual systems

- Treat swatches as structured modules.
- Use thin outlines.
- Use consistent spacing.
- Use muted labels.
- Do not preserve exact color names or codes unless supplied.
- Use the palette system as layout behavior, not mandatory content.

### Footers and base bands

- Use a dark chromatic band only when it grounds a pale or airy composition.
- Keep footer content sparse, small, and edge-aligned.
- Leave the center largely empty when possible.
- Do not convert the footer into a dense sitemap, navigation system, or promotional strip.

- Black-and-gold branding.

Collapse guardrails:

- If the result starts looking like a SaaS dashboard, remove heavy shadows, reduce controls, quiet the status colors, restore serif hierarchy, and use hairline dividers with sparse modules.
- If the result starts looking like luxury branding, remove gold, marble, metallic finishes, jewel tones, glossy gradients, and black-gold contrast; return to matte ivory, charcoal, muted gray, and one earth accent.
- If the result turns glossy or reflective, remove gloss/specular treatments only; keep matte frosted overlays (blur band, translucent fill, quiet border) when overlays over imagery are part of the taste.
- If the result starts looking like a busy magazine layout, remove extra imagery, badges, callouts, and copy; restore one dominant headline or visual mass with open fields.
- If the result starts looking like a generic startup hero, replace bold sans-serif hero type with large serif display type, shrink navigation and CTAs, reduce icons, and move product imagery into rounded contained modules.
- If the result starts looking like an illustration system, remove literal explanatory drawings and use contained atmospheric photography, abstract panels, color slabs, or grid modules.
- If the result starts looking like a colorful status interface, mute all state colors, keep only one accent family, and convert marks into small centered symbols.
- If the result starts looking chaotic, choose one focal system, increase margins, align all elements to rails, and confine detail to one bounded zone.
